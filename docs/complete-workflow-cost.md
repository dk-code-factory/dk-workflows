## Native work and quality

The already-running session owns native skill execution and supported delegation.
The helpers prepare fixtures, capture inputs and read evidence; they do not launch
Codex or Claude Code. Tests use synthetic host records and local transports only.

| Scope | Required work |
| --- | --- |
| Initial fix | Preparation and complete discussion, retained alternatives, every selected task, actual ordinary review descendants and simplifier, verified fixes, another cycle when needed, all seven finalizers and completion checks. |
| Initial incoming review | Preparation and complete discussion, retained architectural analysis, ordinary review descendants and simplifier, independent verification and authorized local review publication. Continue after the controlled author's correction so current clean review and all three finalizers are exercised. |
| Fresh-session reuse | A fresh native coordinator with no inherited conversation reloads necessary guidance/evidence and reuses unchanged accepted work. Refresh current noncacheable readiness; retain original analysis and allowances. |
| Partial recovery | A controlled incomplete native task retains completed siblings. Restore its prerequisite, resume the original claim/continuation and preserve original evidence and budgets. Missing native evidence remains incomplete. |
| Relevant invalidation | Change one declared relevant input. Refresh affected current coverage while retaining valid siblings, historical analysis and original results. |
| Uncertain publication | The local transport applies one authorized write and loses its response. Reconcile the original operation read-only; prove one external write and preserved intent/receipt. |
| Waiting | Include actual coordinator responses that prepare, observe and resume pending local CI under the original deadline. Success is established from current terminal evidence. |

The greeting feature has sourced requirements for rendering names as HTML text and
independent per-call history. Its initial implementation violates both. The
independent evaluator must retain concrete reproductions and match actual findings
and dispositions to these requirements. It must assess false positives, unresolved
findings and complete selected-stage evidence, rather than trust a coordinator's
`complete` flag. A lower bill cannot compensate for a missed finding, skipped
finalizer, stale coverage or weakened authorization/publication checks.

The immutable exercise protocol selects four phases: initial execution with an
incomplete simplifier, fresh recovery, unchanged fresh-session reuse, and relevant
invalidation. A mutable external dispatch marker schedules these phases; it is
neither workflow readiness nor a global semantic input to completed analysis.
The controller removes an original required simplification source only after the
claim is prepared, observes an actual incomplete native leaf, then restores the
same bytes. The native workflow retains its result and completed siblings.

Relevant invalidation adds a normative empty-name requirement in a real PR
commit: display `guest`, retaining the original empty name in per-call history.
The independent feature probe checks the published clean source, first against
both original requirements and then against all three. These behavioral probes
do not replace independent verification of native findings or stage coverage.
Incoming reviewers remain read-only; the external controller supplies actual
author corrections through the original publication contract. Each pushed head
gets pending CI with historical runs retained. After a native current-head check
read, the controller runs real unit tests against that published clean commit,
retaining one original test result per run/attempt without repeating completed CI.

## Accounting

`tests/fixtures/workflow_cost.py` reads the host database's complete parent-child
graph independently of response usage. Every fresh measured root includes all its
turns and descendants. Missing thread records, changed graphs, active turns,
conflicting identities or missing terminal response evidence prevent complete
accounting. The per-thread reader corroborates response records with independently
advancing cumulative counters, actual model/effort/tier and original terminal
output. Copied parent usage is not charged again in a child. Reasoning is already
part of output and is charged once.

Forked host traces can also replay an unfinished parent's start and context before
the child's first settings event, with every copied event re-stamped at child
creation. The reader corroborates the immediate parent and every copied turn
against the host graph and already validated ancestor traces. It excludes that
prefix only in memory, rejecting own or unknown usage, counters, unknown turns
and missing settings boundaries. Original trace hashes and the excluded row count
remain available; no normalized transcript is stored. All own follow-up turns,
response inventories, terminal checks and cumulative deltas still apply. A reader
correction may re-account preserved raw evidence without repeating native work;
retain the original reader's failure and identify the corrected reader revision.

Price each response with the observed model, service tier and context size. The
existing rate card covers GPT-6.1 Sol's fresh input, cache reads, cache writes,
output, tier multipliers and whole-response long-context surcharge. The native
reader rejects nonzero cache writes without independently observed duration.
Unknown prices or duration, missing descendants or incomplete response inventories
make the comparison inconclusive. API-equivalent estimates are not account billing.

Combine recurring initial and recovery costs, including preparation, evidence
loading, coordination, waiting, all descendants and terminal reporting. Keep
implementation, actual PR review and experiment orchestration in separate spending
categories. Explicit mixed/unallocated overhead and cutoff limitations remain
visible; they cannot be silently included in a savings claim or presented as a
complete account bill. Existing spending diagnostics remain available separately.

Private evidence retains original trace references/hashes, graph inventory,
response IDs, frozen resource references, task results and publication journals.
The public report contains route/phase coverage, quality, complete accounting,
baseline/candidate dollars, gate outcomes and limitations. These are opt-in test
artifacts, with the cost-admission and freshness boundary in DESIGN.md; production
workflow state gains no telemetry, summary registry or session runner.
