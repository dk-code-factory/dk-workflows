## Reproduce pricing

The opt-in [pricing ledgers](evidence/complete-workflow-cost/fix-pair-1-baseline.jsonl)
in `docs/evidence/complete-workflow-cost/` contain one JSONL file per exported
attempt. A header identifies source and reader
revisions, graph roots, inventories, buckets and the frozen rate card; thread rows
retain pseudonymous identities, original trace hashes, actual turn controls and
every unique response's usage vector. The five usage columns are input,
cache-read input, cache-write input, output and reasoning output. Reasoning is a
subset of output and is charged once.

From the repository root, verify every exported ledger offline:

```sh
for ledger in docs/evidence/complete-workflow-cost/*.jsonl; do
    python3 tests/fixtures/workflow_ledger.py verify "$ledger"
done
```

All 15 exported ledgers verify offline: 159 distinct threads and 3,459 unique
responses, with no cross-ledger duplicates or overlap with the bounded mixed
parent diagnostic below.

The verifier's `workflow_cost_usd` intentionally excludes nonworkflow buckets.
Pilot and preflight dollars appear in the header's `buckets` costs even though
their recurring workflow cost is zero.

The frozen 2026-11-05 rate card cites the
[model documentation](https://developers.openai.com/api/docs/models/gpt-6.1-sol)
and [pricing documentation](https://developers.openai.com/api/docs/pricing).
It prices fresh input at $2, cached input at $0.10 and output at $10 per million
tokens, with the recorded service-tier and long-context rules. Above 272,000 input
tokens, input/cache charges double and output charges multiply by 1.5 for the
whole response. Observed cache-write counts are zero; nonzero writes without
independently known duration are rejected. These are frozen historical rates,
rather than a claim about current product prices or invoice charges.
The arithmetic uses standard processing prices; account-specific or regional
billing adjustments are not established by these native host records.

Before export, the strict private reader independently closes the host's
parent-child graph, checks every turn's start/terminal evidence, actual settings,
cumulative counters and unique response inventory, and prices all own follow-up
turns. Forked copied ancestor prefixes are excluded only with original host graph
and ancestor-turn corroboration. Earlier reader failures remain original evidence;
the corrected reader reaccounts retained observations without repeating native
work. Summing earlier phase captures would miss later follow-ups and is not the
source of these totals.

The public verifier reproduces arithmetic and inventory consistency without
private conversations, account identities, GitHub or model access. It does not
authenticate host evidence, establish equivalent frozen conditions, prove native
execution or assess quality. Original host and task evidence remains required
for those judgments. Whole shell-command success also does not establish that
every reported driver in a compound command ran or succeeded; the native driver
reader keeps those observations separate.
