description: Draft or update PR titles and descriptions from the actual diff, templates and scope.
---

Resolve PACKAGE_ROOT from this installed skill location. This bundled PR skill can be invoked directly and needs no workflow lifecycle, preparation or invocation tokens. Read [shared inputs, results and publication](../../../docs/pr/contracts.md). Read the complete diff, PR template, linked issue, maintainer conventions and current Decisions. Describe final behavior and validation. Preserve Decisions and unrelated body sections. Synchronize governing scope before review. Draft locally, review the final prose, then publish authorized edits using scripts/publish.py with fresh head/title/body checks. Read references under runtime/dk-pr-description/references when handling Decisions.

Use [the field conventions](../../../runtime/dk-pr-description/references/field-schema.md) when repository evidence leaves a formatting choice open.
