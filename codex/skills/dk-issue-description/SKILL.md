Resolve PACKAGE_ROOT from this installed skill location. This bundled PR skill can be invoked directly and needs no workflow lifecycle, preparation or invocation tokens. Read [shared inputs, results and publication](../../../docs/pr/contracts.md). Inspect issue templates, maintainer conventions and evidence. Draft the concrete trigger, observed/expected behavior, reproduction and relevant validation. Preserve exact user constraints. Review before authorized creation or editing; retain intent and reconcile uncertain writes. Do not infer issue-creation authorization from a PR workflow.
