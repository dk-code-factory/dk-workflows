description: Draft or refine repository-native Git commit messages from actual changes and maintainer conventions.
---

Resolve PACKAGE_ROOT from this installed skill location. This skill works independently of dk-workflows and needs no lifecycle, preparation or invocation tokens. Read [shared inputs, results and publication](../../../docs/contracts.md). Read the diff, repository guidance, commit template and recent human commits. Match established style and preserve authorship/provenance. Keep every message line at most 80 characters. Return the reviewed message and sources; commit only when requested.

Use [the field conventions](../../../runtime/dk-commit-message/references/field-schema.md) when repository evidence leaves a formatting choice open.
